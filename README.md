## ✨ Why Use This?

| Problem | Solution |
|--------|----------|
| 📧 Inbox overflowing with old emails? | **Bulk archive/delete** with custom date ranges. |
| 🏷️ Too many promotions/spam? | **1-click filter** for labels like "Promotions" or "Social". |
| ⏳ Manual cleaning takes forever? | **Automate** with smart exclusions (keep starred/important). |
| 🔒 Privacy concerns? | **No server access**—everything runs locally in your browser. |
